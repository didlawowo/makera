Tool holder repair

1. Tools & Preparation

Tools Required:

Small clamp or bench vise

Suitable nut or fixture with a hole (to compress the tool holder assembly)

2mm Allen key (for grub screw removal/installation)

Preparation:

✔ Ensure the machine is powered off.
✔ Place the tool holder tray on a clean and stable work surface.

2. Disassembly of the Tool Holder

2.1 Remove the Tool Holder

Using a 2mm Allen key, loosen and remove the grub screw located on the side of the tool holder (Figure 1).

Carefully slide the tool holder out of the tray (Figure 2).

2.2 Remove Internal Components

Remove the spring and rear washer from inside the tool holder (Figure 3 & 4).

3. Reassembly of the Tool Holder

3.1 Insert the Spring and Washer

Insert the spring into the tool holder body.

Place the washer over the opening so that it rests against the spring (Figure 5).

3.2 Compressing the Assembly

Insert the silver shaft of the tool holder through a large nut or fixture with a hole.

Using a clamp or bench vise, gently compress the assembly until the washer is flush with the bottom of the tool holder (Figure 6).
⚠ Caution: Ensure the washer remains level and does not tilt during compression.

4. Final Assembly

4.1 Reinstall the Tool Holder

Place the fully assembled tool holder back into the tool holder tray.

Reinsert and securely tighten the grub screw using the 2mm Allen key

✅ Completion Checklist

Spring and washer installed correctly

Washer compressed flush with tool holder base

Tool holder securely reinstalled in tray

Grub screw tightened

You have now successfully reassembled the tool holder.
