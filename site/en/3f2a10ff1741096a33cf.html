My brass nut is stuck

This guide explains how to resolve a common issue affecting the automatic tool changer (ATC), where the machine produces a grinding noise or fails during the homing process.

This issue is typically caused by an over-tightened brass coupling inside the spindle assembly.

Symptoms

You may be experiencing this issue if your machine shows one or more of the following:

  • “ATC home fail” error
  • Loud grinding or slipping noise
  • Tool changer not engaging or releasing
  • Motor spins, but no mechanical movement occurs
  • Tool changer appears stuck

Root Cause

Inside the tool changer assembly, there is a brass threaded coupling connected to a motor-driven shaft.

If this brass piece becomes over-tightened, or there is some debris buildup, the motor cannot generate enough torque to loosen it. As a result:

  • The motor spins
  • The gearbox slips
  • A grinding noise is produced
  • The tool changer fails to operate correctly

Tools Required

  • Allen keys / hex set
  • Screwdrivers
  • Pliers (optional)
  • Rubber grip or cloth
  • Optional: Custom 3D-printed gripping tool

Step-by-Step Solution

1. Remove the Spindle Cover

  • Power off and unplug the machine
  • Remove the outer spindle cover by unscrewing the mounting screws
  • Carefully expose the internal spindle assembly

2. Disassemble the Spindle

  • Locate the 4 long screws at the bottom of the spindle
  • Remove them to separate the spindle housing

3. Remove the Stepper Motor and Mid Section

  • Detach the stepper motor
  • Remove the middle section of the spindle assembly
  • Set all parts aside carefully

4. Remove the Limit Switch Pin

  • Locate the limit switch
  • Remove the steel pin underneath it
  • This will allow access to the tool changer mechanism

5. Extract the Tool Changer Mechanism

  • Pull out the automatic tool changer assembly
  • Ensure nothing is obstructing the removal

6. Identify the Brass Coupling

  • Locate the brass threaded piece on the shaft
  • This is the component that is typically stuck

7. Loosen the Brass Coupling

¶ Important:

  • The gearbox makes it difficult to rotate the shaft backward
  • You may need firm, controlled force

¶ Recommended methods:

Option A: Manual Grip

  • Use a rubber grip or cloth
  • Attempt to loosen the brass piece by hand

Option B: Pliers (Use Carefully)

  • Apply controlled force
  • Avoid damaging the brass surface

Option C: 3D-Printed Tool (Best Method)

  • Use a custom tool that fits around the brass coupling
  • Add a rubber insert for extra grip
  • Provides strong torque without damage

Pro Tip

If the shaft spins while trying to loosen the brass piece:

  • Reinstall the stepper motor into the gearbox
  • This will prevent the shaft from rotating and make loosening easier

Reassembly

Once the brass coupling is loosened:

  1. Reinstall the tool changer mechanism
  2. The brass nut can be positioned anywhere on the shaft.
  3. Replace the limit switch pin
  4. Reassemble the spindle sections
  5. Reattach the stepper motor
  6. Install the spindle cover

Final Check

  • Power on the machine
  • Run a tool change operation

Confirm:

  • No grinding noise
  • Smooth tool engagement
  • No ATC errors
