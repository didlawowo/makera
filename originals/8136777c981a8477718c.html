Makera Z1 Ionizer Module Quick Start

¶ Makera Z1 Ionizer Module Quick Start Guide

The anti-static Ionizer module effectively eliminates static generated during non-metal machining (such as wood, plastic, and resin), preventing chips from sticking to the inner surfaces of the machine and making cleanup easier.

¶ Installation & Use 

https://youtu.be/JF693CFrR7Y

1. Use the control software to move the spindle to the center of the X-axis. 

2. Remove the two M3 placeholder screws on the right side of the spindle housing. 

3. Secure the module to the right side of the spindle using two M3×8 screws. 

4. Connect the module cable to the 3-pin port on the right side of the spindle. 

5. Enable the anti-static function in the control software; the module will operate automatically during machining.
