Upgrade the Software

When?

When you get the update notification in the controller software or get the software upgrade notice at other places.

¶ Firmware Upgrade

  1. Download the latest firmware from our official website: https://www.makera.com/pages/software
  2. Open the controller software and connect to the Carvera.
  3. Click the top-right ‘other function’ menu and open the software update popup window.
  4. Click the ‘upgrade’ button and select the latest firmware you just downloaded.
  5. Click upload, and wait for the uploading to finish, the machine will be reset automatically by default. Or you can manually reset the machine.
  6. After resetting, you can check if the firmware version has been updated by reopening the upgrade window, or manually input the ‘version’ command in the MDI window.

 

¶ Controller Software Upgrade

For control software, just install the latest version and you are ready to use.
