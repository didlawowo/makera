Laser

¶ How to refocus the laser.

 

• Please use UV safety goggles for this procedure.

• Remove the silicone cap from the laser head.

• Add an MDF spoil board for this test.

• Start the sample laser file (AudreyHepburnSmall)  and stop the file when the laser operation starts. (Include a Z probe in the run config.)

• From the top toolbar in the controller, enable the laser and enable the test laser function, the power of the laser is set to 0.1 power, so it won’t burn the material.

• On the laser’s head is a tunable knob that focuses the laser, use this to manually focus the laser.

• (Look at the laser dot and make sure it is set to its most focused position)

• rerun the file and test if the laser has been focused.

 

¶ How to realign the laser

 

After the laser has been focused and you need to adjust the offset distance, follow the below steps:

 

1. Enter the laser mode, open the laser test again, go to x=0, y=0, z=0,  

2. Measure the laser red pointer offset in relation to the anchor point 1 position.

3. In the settings window in the laser section, you can modify the offset values of X,Y, and Z.

4. Apply the new values and reset the machine.

5. Test to see if the offset modification was successful.
